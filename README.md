## 🌈 Featured project

### [QuickLook CAD Preview](https://github.com/Ghost-Morgan/QuickLook-CAD-Preview)

An open-source QuickLook plugin for interactive DWG and DXF previews on Windows. Orbit, pan, zoom, and inspect large drawings with adaptive detail.
